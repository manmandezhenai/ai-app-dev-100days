# Day19：文件权限、用户管理与压缩解压

## 【核心知识点】

### 1. 文件权限基础规则

- Linux 文件权限分为三组，依次为：所有者权限、所属组权限、其他用户权限
- 每组包含三种权限：`r`（读）、`w`（写）、`x`（执行），无对应权限用 `-` 表示
- 数字权限表示法：`r=4`、`w=2`、`x=1`，每组权限值为对应权限数字之和

| 权限组合  | 数字值 | 权限说明     |
|-------|-----|----------|
| `rwx` | 7   | 可读可写可执行  |
| `rw-` | 6   | 可读可写不可执行 |
| `r-x` | 5   | 可读可执行不可写 |
| `r--` | 4   | 仅可读      |

### 2. 权限与归属修改命令

- 修改文件权限：`chmod 权限值 目标文件`
    - 数字模式示例：`chmod 755 test.py`
    - 符号模式示例：`chmod u+x test.py` 给所有者添加执行权限
- 修改文件所有者：`chown 用户名 目标文件`，修改所有者需管理员权限
- 修改文件所属组：`chgrp 组名 目标文件`

### 3. 用户与用户组基础操作

- 用户操作：
    - `useradd 用户名`：创建新用户
    - `passwd 用户名`：设置或修改用户密码
    - `userdel -r 用户名`：删除用户并同步删除家目录
- 用户组操作：
    - `groupadd 组名`：创建新用户组
    - `groupdel 组名`：删除指定用户组

### 4. 压缩解压常用命令

- tar 打包压缩（gzip 格式）：
    - 压缩：`tar -zcvf 压缩包名.tar.gz 待压缩文件/目录`
    - 解压：`tar -zxvf 压缩包名.tar.gz`
    - 解压到指定目录：`tar -zxvf 压缩包名.tar.gz -C 目标目录`
- zip 格式处理：
    - 压缩：`zip -r 压缩包名.zip 待压缩文件/目录`
    - 解压：`unzip 压缩包名.zip`
    - 解压到指定目录：`unzip 压缩包名.zip -d 目标目录`

## 【今日易错点】

1. 数字权限只写两位或一位会导致权限设置错误，必须是三位数字分别对应所有者、所属组、其他用户
2. 执行脚本文件提示 Permission denied，通常是文件缺少 `x` 执行权限，需用 `chmod` 添加
3. `tar` 命令中 `f` 参数必须放在最后紧跟文件名，参数顺序错误会导致命令执行失败
4. 修改文件所有者和用户组需要管理员权限，普通用户直接执行 `chown` / `chgrp` 会报错
5. 解压 `zip` 文件未指定目录会直接散落在当前目录，需解压到目录请追加 `-d` 参数
