# Day08：文件读写操作（文本、二进制文件）

## 【核心知识点】

### 1. 文件打开与关闭基础

```python
文件对象 = open(文件路径, 打开模式, encoding=编码格式)
文件操作逻辑
文件对象.close()
```

- 使用 `open()` 函数打开文件，返回文件操作对象
- 操作完成后必须调用 `close()` 方法关闭文件，释放系统资源
- 文本文件需指定 `encoding = "UTF-8"`，避免中文乱码

| 打开模式 | 功能说明        | 特点                  |
|------|-------------|---------------------|
| `r`  | 只读模式打开文本文件  | 文件不存在则报错，指针在文件开头    |
| `w`  | 写入模式打开文本文件  | 文件不存在则创建，存在则清空覆盖原内容 |
| `a`  | 追加模式打开文本文件  | 文件不存在则创建，存在则在末尾追加内容 |
| `rb` | 只读模式打开二进制文件 | 用于图片、视频、压缩包等非文本文件   |
| `wb` | 写入模式打开二进制文件 | 用于二进制文件写入与复制        |

### 2. 文本文件常用读写方法

- 读取方法：
    - `read()`：一次性读取全部内容，返回字符串
    - `readline()`：读取一行内容，返回单行字符串
    - `readlines()`：读取所有行，返回每行内容组成的列表
- 写入方法：
    - `write(字符串)`：向文件写入字符串内容，返回写入字符数
    - `writelines(字符串列表)`：向文件写入列表中所有字符串，不自动换行

### 3. with 上下文管理器（工程推荐写法）

```python
with open(文件路径, 打开模式, encoding=编码格式) as 文件对象:
    文件操作逻辑
```

- 代码块执行完毕后自动关闭文件，无需手动调用 `close()`
- 即使代码执行异常也会自动释放文件资源，避免资源泄漏
- 工程开发中统一使用该方式操作文件

### 4. 二进制文件操作

- 适用场景：图片、音频、视频、压缩包等非文本文件的复制、备份
- 读写方式与文本文件一致，打开模式使用 `rb` / `wb`，无需指定编码
- 典型应用：文件复制，读取源文件二进制内容写入目标文件

## 【今日易错点】

1. 打开文件后忘记调用 `close()` 关闭，会持续占用系统资源，推荐统一使用 `with` 语法
2. 使用 `w` 模式打开已存在的文件会直接清空原内容，需保留原内容请使用 `a` 模式
3. 读取文本文件不指定 `encoding` 参数，Windows 环境下易出现中文乱码
4. 使用 `r` 模式读取不存在的文件会触发 `FilNotFoundError`，需提前判断或捕获异常
5. 路径包含反斜杠未转义会被识别为转义字符，推荐使用正斜杠或原始字符串
