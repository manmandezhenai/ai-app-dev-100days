# Day11：批量文件遍历与数据清洗基础

## 【核心知识点】

### 1.目录遍历常用方法

单层目录遍历：

```python
import os

文件名列表 = os.listdir(目标目录路径)
for 文件名 in 文件名列表:
    处理单个文件 / 目录
```

递归多层目录遍历：

```python
import os

for 当前目录路径, 子目录列表, 文件列表 in os.walk(根目录路径):
    for 文件名 in 文件列表:
        拼接完整路径并处理文件
```

- `os.listdir()`：仅返回指定目录下的文件与子目录名称，不进入子目录递归
- `os.walk()`：逐层遍历所有子目录，每次返回目录路径、子目录列表、文件列表
- 完整路径必须使用 `os.path.join(目录路径, 文件名)` 拼接，保证跨平台兼容

### 2. 文件过滤筛选

- 后缀过滤：使用 `endswith()` 判断文件后缀，支持传入元组匹配多种后缀
- 名称过滤：使用 `startswith()`、`in` 关键字匹配文件名特征
- 类型判断：`os.path.isfile(路径)` 判断是否为文件；`os.path.isdir(路径)` 判断是否为目录
- 典型应用：批量筛选 `.txt`、`.csv` 等指定格式的业务数据文件

### 3. 文本数据基础清洗

- 空白清理：`strip()` 去除每行首尾空白，过滤空行
- 内容替换：`replace()` 统一分隔符、去除冗余符号
- 格式统一：统一大小写、统一编号格式，消除数据不一致
- 无效过滤：按规则剔除异常行、无效数据行

### 4. 批量文件处理标准流程

1. 遍历目标目录，筛选符合条件的文件
2. 逐个读取文件原始内容
3. 按规则执行逐行清洗逻辑
4. 将清洗后内容写入目标文件
5. 输出处理统计结果

## 【今日易错点】

1. 手动字符串拼接路径易引发跨平台错误，必须使用 `os.path.join()` 拼接路径
2. `os.walk()` 首个返回值是目录路径，直接当作文件读取会触发 IO 错误
3. 未判断文件类型直接处理，将子目录名当作文件操作会引发报错
4. 清洗后直接覆盖原文件无备份，数据异常后无法恢复，建议先写入临时文件
5. 未处理空行与异常行，遇到格式不一致的数据会导致程序中断
