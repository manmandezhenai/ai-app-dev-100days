# Day05：字符串处理与常用内置函数

## 【核心知识点】

### 1. 字符串基础操作

- 索引访问：`字符串[下标]`，下标从 0 开始，支持负数下标，-1 表示最后一个字符
- 切片操作：`字符串[start:end:step]`，左闭右开区间，step 为步长（省略默认值为 1）
- 拼接操作：使用 `+` 运算符拼接多个字符串
- 重复操作：使用 `*` 运算符重复字符串指定次数
- 核心特性：字符串为不可变类型，修改操作会生成新字符串，原字符串保持不变

### 2. 常用字符串处理方法

| 方法名                   | 功能用途                 | 示例效果                                     |
|-----------------------|----------------------|------------------------------------------|
| `strip()`             | 去除字符串首尾空白字符（空格、换行符等） | `"  abc  ".strip()` → `"abc"`            |
| `split(分隔符)`          | 按指定分隔符拆分字符串，返回列表     | `"a,b,c".split(",")` → `["a", "b", "c"]` |
| `join(列表)`            | 将字符串列表按指定字符拼接为完整字符串  | `"-".join(["a", "b", "c"])` → `"a-b-c"`  |
| `replace(旧内容, 新内容)`   | 将字符串中旧内容替换为新内容       | `"hello".replace("h", "H")` → `"Hello"`  |
| `upper()` / `lower()` | 将字符串全部转为大写 / 小写      | `"Abc".upper()` → `"ABC"`                |
| `startswith(前缀)`      | 判断是否以指定前缀开头，返回布尔值    | `"test.py".startswith("test")` → `True`  |
| `endswith(后缀)`        | 判断是否以指定后缀结尾，返回布尔值    | `"test.py".endswith(".py")` → `True`     |

### 3. 字符串格式化方式

```python
# f-string 格式化（工程推荐）
f"固定文本{变量名}固定文本"

# format 方法
"{} {}".format(值1, 值2)
```

- 浮点数精度控制：通过 `:.2f` 指定保留 2 位小数，可用于两种格式化方式
- f-string 支持直接在大括号内写入简单表达式，代码可读性更强

### 4. 通用内置函数与关键字

- `len(对象)`：返回字符串长度，也可用于列表、字典等其他数据结构
- `str(数据)`：将其他类型数据转为字符串类型
- `max(字符串)`：返回字符串中 ASCII 码值最大的字符
- `min(字符串)`：返回字符串中 ASCII 码值最小的字符
- `in` 关键字：判断子字符串是否存在于目标字符串中，返回布尔值

## 【今日易错点】

1. 字符串为不可变类型，直接通过下标赋值修改会触发 `TypeError`，需用 `replace()` 或拼接生成新字符串
2. 字符串索引超出有效范围会触发 `IndexError`，负数索引从 -1 开始计数，不可越界
3. `split()` 方法的分隔符不存在时，会返回包含原字符串的单元素列表，不会抛出错误
4. f-string 内外引号混用会引发语法错误，外层双引号时内层需使用单引号
5. `strip()` 仅去除首尾空白字符，字符串中间的空白不会处理，需替换请使用 `replace()`
