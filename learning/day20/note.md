# Day20：Shell 基础命令与远程连接操作

## 【核心知识点】

### 1. Shell 变量与环境变量

- 自定义变量定义：`变量名=值`，等号两侧不能有空格，引用变量使用 `$变量名`
- 环境变量定义：`export 变量名=值`，定义后当前 Shell 及子进程均可访问
- 常用内置环境变量：
    - `$PWD`：当前所在目录绝对路径
    - `$HOME`：当前用户家目录路径
    - `$USER`：当前登录用户名
    - `$?`：上一条命令的执行返回码，0 表示成功，非 0 表示失败

### 2. 管道与重定向

- 管道符 `|`：将左侧命令的标准输出，作为右侧命令的标准输入
- 输出重定向：
    - `命令 > 文件`：将命令输出覆盖写入目标文件
    - `命令 >> 文件`：将命令输出追加写入目标文件末尾
- 输入重定向：`命令 < 文件`，从文件读取内容作为命令的输入
- 典型组合：`ls | grep 关键词` 筛选目录内容，`cat file | wc -l` 统计文件行数

### 3. SSH 远程连接

- 基础连接语法：`ssh 用户名@服务器IP地址`
    - 默认连接端口为 22，指定端口需追加 `-p 端口号` 参数
    - 免密登录配置：本地生成 SSH 密钥，将公钥写入服务器 `~/.ssh/authorized_keys`
    - 远程单条命令执行：`ssh 用户名@地址 "执行命令"`，无需登录交互终端直接运行命令

### 4. SCP 文件传输

- 本地上传到远程：`scp 本地文件路径 用户名@服务器地址:远程目标路径`
- 远程下载到本地：`scp 用户名@服务器地址:远程文件路径 本地目标路径`
    - 传输目录需追加 `-r` 参数，递归传输目录内所在内容
    - 指定端口使用大写 `-P` 参数，注意与 ssh 小写端口参数区分
    - 传输过程显示进度与详情，可追加 `-v` 参数查看调试信息

## 【今日易错点】

1. Shell 定义变量时等号两侧添加空格会触发语法报错，变量名、等号、值必须紧贴
2. scp 指定端口使用大写 `-P`，ssh 使用小写 `-p`，参数大小写混淆会导致命令执行失败
3. 输出重定向使用 `>` 会直接覆盖原文件内容，需保留原内容请使用 `>>` 追加模式
4. 远程路径拼写错误会导致文件传输失败，建议先通过 ssh 登录确认目标路径存在
5. 管道符前的命令执行失败，会导致后续命令接收空输入，需先确认前置命令可正常输出
