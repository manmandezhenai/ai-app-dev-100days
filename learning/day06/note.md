# Day06：模块导入、包管理与pip、虚拟环境实操

## 【核心知识点】

### 1. 模块导入基础语法

完整导入语法：

```python
import 模块名
import 模块名 as 别名
```

按需导入语法：

```python
from 模块名 import 函数名 / 类名
from 模块名 import *
```

- 导入语句统一放在文件顶部，按「标准库 → 第三方库 → 本地模块」分层排列，层间空一行
- 使用别名可简化模块名的调用，提升代码可读性
- `from 模块名 import *` 会导入模块全部内容，易引发命名冲突，工程中不推荐使用

### 2. 常用标准库模块

| 模块名      | 核心功能                 | 典型应用场景            |
|----------|----------------------|-------------------|
| `sys`    | 获取 Python 解释器与系统环境信息 | 版本校验、路径管理、命令行参数获取 |
| `os`     | 操作系统交互、文件与目录操作       | 路径拼接、目录创建、环境变量读取  |
| `random` | 随机数生成与随机选择           | 随机抽样、随机排序、模拟随机场景  |
| `math`   | 基础数学运算函数             | 数值计算、取整、幂运算       |

### 3. pip 包管理常用命令

- `pip install 包名`：安装指定第三方包，可追加 `==版本号` 指定安装版本
- `pip uninstall 包名`：卸载已安装的第三方包
- `pip list`：列出当前环境所有已安装的包与对应版本
- `pip freeze > requirements.txt`：导出当前环境所有依赖包与版本到指定文件
- `pip install -r requirements.txt`：批量安装依赖文件中列出的所有包
- `python -m pip install --upgrade pip`：升级 pip 工具自身版本

### 4. 虚拟环境实操要点

- 创建命令：`python -m venv 虚拟环境目录名`，在当前目录生成独立虚拟环境文件夹
- 激活命令：Windows 系统执行 `venv\Scripts\activate`，Mac / Linux 执行 `source venv/bin/activate`
- 退出命令：执行 `deativate` 即可退出当前虚拟环境，回到系统 Python 环境
- 核心作用：隔离不同项目的依赖包，避免多项目版本冲突
- 工程规范：项目依赖统一写入 `requirements.txt`，不将虚拟环境目录提交到 Git

## 【今日易错点】

1. 未激活虚拟环境直接安装包，会将依赖安装到系统 Python 环境，导致项目依赖不一致
2. Python 文件名与导入的模块名重名，会优先导入本地文件引发导入错误
3. 多类导入语句混合排列不按规范分层，不符合 PEP8 代码规范且可读性差
4. 使用 `pip freeze` 导出依赖时未激活对应虚拟环境，会导出系统全局依赖
5. 卸载包时误删依赖关联包，会导致原有功能无法正常运行
