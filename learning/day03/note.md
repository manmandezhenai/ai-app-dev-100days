# Day03：函数定义、参数分类与返回值

## 【核心知识点】

### 1. 函数定义与基础调用

```python
def 函数名(参数列表):
    """函数功能说明文档字符串"""
    函数内部执行逻辑
    return 返回值
```

- 函数使用 `def` 关键字定义，必须先定义后调用
- 函数名遵循蛇形命名规范，见名知意
- 三引号包裹的 docstring 用于说明函数功能，可通过 `help(函数名)` 查看
- 调用方式：`函数名(参数值)`，执行函数内全部逻辑

### 2. 函数参数分类

| 参数类型  | 定义方式              | 调用规则           | 特点               |
|-------|-------------------|----------------|------------------|
| 位置参数  | 直接定义变量名           | 按顺序传入参数，数量必须匹配 | 调用时必须传入，无默认值     |
| 默认参数  | 定义时赋值 `参数名 = 默认值` | 可省略不传，不传则使用默认值 | 必须放在位置参数之后       |
| 关键字参数 | 调用时指定 `参数名 = 值`   | 可不按定义顺序传入      | 清晰指定参数含义，适合多参数场景 |

### 3. return 返回值

- `return` 用于将函数执行结果返回给调用方，同时终止函数执行
- 支持返回单个值、多个值，多返回值默认以元组形式接收
- 未写 return 或 return 后无值时，函数默认返回 `None`

### 4. 变量作用域基础

- 局部变量：在函数内部定义，仅在函数内部生效，函数外部无法访问
- 全局变量：在函数外部定义，函数内部可读取，默认不可直接修改
- 变量查找优先级：局部作用域 → 全局作用域

## 【今日易错点】

1. 函数必须先定义后调用，调用语句写在定义前会触发 `NameError`
2. 默认参数必须定义在位置参数之后，顺序颠倒会触发语法报错
3. 位置参数调用时数量不匹配，会触发参数数量不符的报错
4. 忘记函数默认返回 `None`，直接对返回结果做运算会引发类型错误
5. 函数内部直接修改全局变量会创建同名局部变量，不会修改外部值
