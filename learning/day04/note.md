# Day04：内置数据结构进阶（列表、字典、元组、集合常用方法）

## 【核心知识点】

### 1. 列表（list）常用操作

- 定义方式：使用 `[]` 包裹元素，元素有序、可重复、支持修改
- 索引访问：通过 `列表[下标]` 获取元素，下标从 0 开始计数
- 常用操作方法：
    - `append(元素)`：在列表末尾添加单个元素
    - `pop(下标)`：删除指定下标元素并返回，不传下标默认删除末尾元素
    - `insert(下标, 元素)`：在指定下标位置插入元素
    - `remove(元素)`：删除列表中第一个匹配的元素
    - 切片语法：`列表[start:end]` 获取指定范围子列表，左闭右开区间

### 2. 字典（dict）常用操作

- 定义方式：使用 `{键: 值}`键值对结构，键唯一不可重复
- 两种取值方式：
    - `字典[键]`：键不存在时直接触发报错
    - `字典.get(键, 默认值)`：键不存在时返回默认值，运行更安全
- 常用操作方法：
    - `字典[键] = 值`：新增键值对或修改已有键对应的值
    - `keys()`：获取字典中所有键的集合
    - `values()`：获取字典中所有值的集合
    - `items()`：获取所有键值对，常用于遍历字典

### 3. 元组（tuple）基础特性

- 定义方式：使用 `()` 包裹元素，元素有序、创建后不可修改
- 支持索引与切片操作，语法规则与列表完全一致
- 适用场景：存储无需修改的固定数据集合，可作为字典的键使用

### 4. 集合（set）基础特性

- 定义方式：空集合必须用 `set()`创建，非空集合可用 `{元素}` 包裹
- 核心特性：元素无序、自动去重、不允许重复值存在
- 常用操作方法：
    - `add(元素)`：向集合中添加单个元素
    - `remove(元素)`：删除集合中指定元素
    - 典型应用：对列表执行去重处理

## 【今日易错点】

1. 列表索引超出有效范围会触发 `IndexError`，访问前需确认下标长度
2. 用 `[]` 访问字典不存在的键会触发 `KeyError`，安全取值优先使用 `get()` 方法
3. 元组元素不可修改，尝试对元组元素赋值会触发 `TypeError`
4. 直接写 `{}` 会被识别为空字典，创建空集合必须使用 `set()`
5. 集合元素无序无法通过下标索引访问，有序场景请使用列表
