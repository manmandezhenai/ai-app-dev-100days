# Day02：分支结构与循环结构（if、for、while）

## 【核心知识点】

### 1. if 单分支与双分支结构

单分支语法：

```python
if 条件:
    条件成立时执行的逻辑
```

双分支语法：

```python
if 条件:
    条件成立时执行的逻辑
else:
    条件不成立时执行的逻辑
```

- 条件判断结果为布尔值，`True` 时执行分支内代码
- 分支内代码必须保持统一缩进，标准为 4 个空格
- 常用比较运算符：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）

### 2. 多分支与嵌套分支

多分支语法：

```python
if 条件1:
    条件1成立时执行的逻辑
elif 条件2:
    条件2成立时执行的逻辑
else:
    所有条件都不成立时执行的逻辑
```

嵌套分支语法：

```python
if 外层条件:
    外层条件成立执行逻辑
    if 内层条件:
        内层条件成立执行逻辑
```

- `elif` 可设置多个，按顺序判断，命中一个后后续分支不再执行
- 嵌套分支需严格控制缩进层级，避免逻辑混乱

### 3. for 循环基础

基础遍历语法：

```python
for 临时变量 in 可迭代对象:
    循环体执行逻辑
```

- 常见可迭代对象：字符串、列表、字典、`range` 生成的数字序列
- `range(n)` 生成 0 到 n - 1 的整数序列，循环共执行 n 次
- `range(start, end)` 生成左闭右开区间的整数序列

### 4. while 循环基础

基础语法：

```python
while 循环条件:
    循环体执行逻辑
    更新循环条件相关变量
```

- 循环条件为 `True` 时持续执行，为 `False` 时退出循环
- 必须在循环体内更新条件变量，避免造成无限循环
- 适用于循环次数不固定、按条件终止的场景

### 5. 循环控制语句

- `break`：立刻终止当前整个循环，不再执行后续迭代
- `continue`：跳过本次循环剩余代码，直接进入下一次循环
- 两个语句均只作用于当前所在层级的循环

## 【今日易错点】

1. 分支与循环体缩进不统一，会触发 `IndentationError` 语法报错
2. 条件判断误用赋值符 `=`，相等比较必须使用 `==`
3. `range()` 生成序列为左闭右开，容易遗漏或多算边界值
4. `while` 循环忘记更新条件变量，会导致程序进入死循环
5. 嵌套循环中 `break` 只能跳出当前层循环，无法直接终止外层循环
