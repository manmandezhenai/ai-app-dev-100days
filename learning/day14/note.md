# Day14：正则表达式基础应用与文本提取

## 【核心知识点】

### 1. re 模块基础匹配函数

导入与基础调用：

```python
import re

匹配结果 = re.match(正则表达式, 目标字符串)
匹配结果 = re.search(正则表达式, 目标字符串)
结果列表 = re.findall(正则表达式, 目标字符串)
```

- `re.match()`：从字符串开头匹配，开头不匹配则返回 None
- `re.search()`：扫描全文，返回第一个匹配结果
- `re.findall()`：扫描全文，返回所有匹配项组成的列表
- 匹配成功可通过 `group()` 方法获取匹配到的内容

### 2. 常用基础元字符

| 元字符  | 功能说明               | 匹配示例                 |
|------|--------------------|----------------------|
| `.`  | 匹配任意单个字符（换行符除外）    | `a.c` 匹配 `abc`、`a1c` |
| `\d` | 匹配任意数字，等价于 `[0-9]` | `\d+` 匹配连续数字         |
| `\w` | 匹配字母、数字、下划线        | `\w+` 匹配连续单词字符       |
| `\s` | 匹配任意空白字符（空格、制表符等）  | `a\sb` 匹配 `a b`      |
| `*`  | 匹配前一个字符 0 次或多次     | `ab*` 匹配 `a`、`abb`   |
| `+`  | 匹配前一个字符 1 次或多次     | `ab+` 匹配 `ab`、`abb`  |
| `?`  | 匹配前一个字符 0 次或 1 次   | `ab?` 匹配 `a`、`ab`    |
| `^`  | 匹配字符串开头            | `^hello` 匹配开头的 hello |
| `$`  | 匹配字符串结尾            | `world$` 匹配结尾的 world |
| `[]` | 匹配括号内任意一个字符        | `[abc]` 匹配 a/b/c 中一个 |

### 3. 分组提取语法

```python
import re

结果 = re.search(正则表达式, 目标字符串)
完整内容 = 结果.group(0)
第1组内容 = 结果.group(1)
所有分组内容 = 结果.groups()
```

- 使用 `()` 包裹需要提取的部分，形成捕获分组
- `group(0)` 返回完整匹配内容，分组从 `group(1)` 开始按顺序编号
- `findall()` 搭配分组时，返回所有分组内容组成的列表
- 适用于文本中提取指定字段，如手机号、邮箱、编号等

### 4. 替换与分割基础操作

- 替换：`re.sub(正则, 替换内容, 目标字符串)`，将匹配到的内容替换为指定文本
- 分割：`re.split(正则, 目标字符串)`，按匹配规则分割字符串返回列表
- 标志参数：追加 `re.IGNORECASE` 可忽略大小写匹配

## 【今日易错点】

1. `re.match()` 仅从字符串开头匹配，全文匹配请使用 `re.search()` 或 `re.findall()`
2. 匹配 `.`、`*`、`?` 等特殊字符需加 `\` 转义，否则会被识别为元字符
3. 分组提取时索引从 1 开始，误写 `group(0)` 会返回完整匹配而非目标分组
4. 正则默认区分大小写，忽略大小写需在函数中追加 `re.IGNORECASE` 参数
5. 元字符 `+` 和 `*` 为贪婪匹配，会尽可能多匹配内容，按需搭配 `?` 转为非贪婪
