# Day01：Python 环境验证与基础语法入门（变量、数据类型、输入输出）

## 【核心知识点】

### 1. 变量定义与命名规范

- 变量赋值语法：使用 `=` 进行赋值，无需提前声明类型
- 合法命名：只能包含字母、数字、下划线，且不能以数字开头
- 工程规范：统一使用蛇形命名法，变量名见名知意
- 禁止规则：禁止使用 Python 关键字作为变量名

### 2. 基础数据类型

| 类型标识    | 中文名称 | 示例               | 应用场景           |
|---------|------|------------------|----------------|
| `int`   | 整数   | `10`、`-5`、`0`    | 计数、编号、年龄等整数场景  |
| `float` | 浮点数  | `3.14`、`-0.5`    | 价格、身高、比例等带小数场景 |
| `str`   | 字符串  | `"张三"`、`'Hello'` | 文本、名称、描述等内容存储  |
| `bool`  | 布尔值  | `True`、`False`   | 条件判断、状态标记场景    |

### 3. print 输出函数

- 基础调用：`print(输出内容)` 向控制台打印内容
- 多值输出：多个内容用逗号分隔，输出时自动用空格拼接
- 结束符控制：通过 `end` 参数修改输出结尾，默认是换行符（`\n`）

### 4. input 输入函数

- 基础调用：`input(提示文字)` 暂停程序，等待用户输入后继续
- 返回值特性：无论输入内容是什么，返回值类型均为字符串
- 类型转换：需使用 `int()`、`float()` 将输入内容转为数值类型使用

## 【今日易错点】

1. 变量名以数字开头会触发语法报错，命名必须以字母或下划线开头
2. `input()` 返回值默认为字符串，直接参与数值运算会触发类型错误
3. 字符串引号必须成对出现，单双引号混用会导致语法报错
4. 布尔值 `True` 和 `False` 首字母必须大写，小写会被识别为普通变量
5. Python 对变量名大小写敏感，`name` 和 `Name` 是两个完全不同的变量
