# Day09：面向对象编程基础（类与实例、属性、方法）

## 【核心知识点】

### 1. 类的定义与实例创建

```python
class 类名:
    """类功能说明文档字符串"""
    类内部属性与方法定义
```

实例化语法：

```python
实例变量名 = 类名()
```

- 使用 `class` 关键字定义类，类名遵循大驼峰命名规范
- 类是对象的模板，实例是类创建出的具体对象
- 一个类可以创建多个独立的实例对象，互不干扰

### 2. 构造方法 `__init__` 与实例属性

```python
class 类名:
    def __init__(self, 参数1, 参数2):
        self.属性名1 = 参数1
        self.属性名2 = 参数2
```

- `__init__` 是构造方法，实例化对象时自动执行，无需手动调用
- 第一个参数固定为 `self`，代表当前实例对象本身
- 实例属性通过 `self.属性名` 定义，每个实例拥有独立的属性副本
- 实例化时传入的参数会传递给 `__init__` 方法，完成属性初始化

### 3. 实例方法定义与调用

```python
class 类名:
    def 方法名(self, 其他参数):
        方法内部执行逻辑
        self.属性名  # 访问自身实例属性
```

- 定义在类内部的函数称为方法，第一个参数必须为 `self`
- 调用方式：`实例名.方法名(参数)`，调用时无需手动传入 `self`
- 方法内部通过 `self` 访问当前实例的属性和其他方法

### 4. 实例属性与方法访问规则

- 属性访问：`实例名.属性名`，可读取或修改属性值
- 方法调用：`实例名.方法名()`，执行对应方法逻辑
- 不同实例的属性相互独立，修改一个实例的属性不会影响其他实例
- 访问不存在的属性或方法会触发 `AttributeError`

## 【今日易错点】

1. 实例方法第一个参数必须写 `self`，漏写会导致调用时报参数数量不匹配错误
2. `__init__` 是构造方法，禁止手动添加 `return` 返回值，否则会触发 `TypeError`
3. 方法内访问实例属性漏写 `self`，会被识别为局部变量，引发 `NameError`
4. 类名应使用大驼峰命名法，与函数的蛇形命名区分，符合工程规范
5. 直接访问未在构造方法中定义的实例属性，会触发 `AttributeError`
