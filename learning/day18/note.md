# Day18：Linux 基础命令（目录导航、文件查看、基础操作）

## 【核心知识点】

### 1. 目录导航命令

- `pwd`：查看当前所在目录的绝对路径
- `cd 目标路径`：切换到指定目录
    - `cd ~`：切换到当前用户家目录
    - `cd ..`：切换到上一级目录
    - `cd -`：切换到上一次所在的目录
- `ls`：列出当前目录下的文件与子目录
    - `ls -l`：以长格式显示，包含权限、大小、修改时间等信息
    - `ls -a`：显示所有文件，包括隐藏文件
    - `ls -lh`：人性化显示文件大小，自动换算单位

### 2. 文件查看命令

| 命令         | 功能用途        | 常用参数说明                          |
|------------|-------------|---------------------------------|
| `cat 文件名`  | 一次性输出文件全部内容 | 适合查看体积较小的文件                     |
| `head 文件名` | 查看文件开头部分内容  | `-n 行数` 指定显示前 N 行               |
| `tail 文件名` | 查看文件末尾部分内容  | `-n 行数` 指定显示后 N 行；`-f` 实时追踪新增内容 |
| `more 文件名` | 分页查看大文件     | 空格翻页，按 q 退出查看                   |

### 3. 文件与目录基础操作

- `touch 文件名`：创建空文件，文件已存在则更新修改时间
- `mkdir 目录名`：创建空目录；`mkdir -p 多级路径` 递归创建多层目录
- `rm 目标`：删除文件或目录
    - 删除文件直接执行 `rm 文件名`
    - 删除目录需加 `-r` 参数：`rm -r 目录名`
    - `-f` 参数强制删除，不弹出确认提示
- `cp 源路径 目录路径`：复制文件或目录，复制目录需追加 `-r`
- `mv 源路径 目标路径`：移动文件 / 目录，或文件重命名

### 4. 路径基础规则

- 绝对路径：从根目录 `/` 开头的完整路径，任意位置都可准确定位
- 相对路径：相对于当前目录的路径，无需从根目录开头
- 隐藏文件：文件名以 `.` 开头，默认不显示，需使用 `ls -a` 查看

## 【今日易错点】

1. `rm -rf` 会强制递归删除且无法恢复，执行前务必确认目标路径准确
2. 切换不存在的目录路径会触发报错，可先用 `ls` 确认目标目录存在
3. 复制 / 删除目录时忘记加 `-r` 参数，会导致命令执行失败
4. 相对路径依赖当前所在目录，不同目录下执行相同相对路径结果不同
5. 文件名包含空格时需用引号包裹，否则会被识别为多个参数
